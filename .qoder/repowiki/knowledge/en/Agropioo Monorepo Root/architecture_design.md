The root orchestrates three runtime layers around a Next.js App Router: `app/` serves the multi-locale marketing site and farmer dashboard, `lib/` provides cross-cutting services (auth, i18n, validation, HTTP, mailer, Supabase) consumed by both `app/` and tests, and `catalog/` supplies the source-of-truth English translations plus per-locale dictionaries synced to Supabase at runtime. Locale routing is centralized in `proxy.ts`, which rewrites bare URLs to `/en/<path>` while letting explicit locale slugs pass through, excluding all API and farmer-app routes via its matcher. The `sync:translations` script bridges `catalog/` and Supabase, and `vitest.config.ts` scopes tests to `lib/` and `catalog/` using the same `@/` path alias configured in `tsconfig.json`. ESLint extends Next's core-web-vitals + TypeScript rules globally across the repo.
