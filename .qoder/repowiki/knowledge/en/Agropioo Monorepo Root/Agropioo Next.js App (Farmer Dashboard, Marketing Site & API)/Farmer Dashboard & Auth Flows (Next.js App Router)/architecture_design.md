Organized as a Next.js `app/(farmer)/` route group with two layout layers: the root `layout.tsx` injects Google fonts (Playfair Display, DM Sans, Geist Mono), metadata, viewport theme color, and the `<html>/<body>` shell; the nested `(dashboard)/layout.tsx` is the authenticated app shell that calls `requireSessionPage()` to gate access, then wraps children in `AppSidebar` + `BottomTabBar` with responsive main content. Feature pages live under `(dashboard)/` (advisor, dashboard, detect, farms, notifications, prices, records, settings, weather, more) and each page folder follows a thin `page.tsx` + co-located view component (`*-view.tsx`, `detect-upload.tsx`, `farm-form.tsx`, `record-form.tsx`) pattern, with static `demo-data.ts` files providing mock data. Authenticated routes are protected by the dashboard layout, while guest-only routes (`forgot-password/`, `reset-password/`) use their own layouts calling `requireGuestPage()`. The `verify/` layout enforces an OTP or reset pass via `readValidPass` before rendering. Dynamic segments like `farms/[id]` resolve params as Promises and call `notFound()` when missing. Navigation between screens uses Next.js `Link` and shared `PageHeader` from `@/components/shell`.
