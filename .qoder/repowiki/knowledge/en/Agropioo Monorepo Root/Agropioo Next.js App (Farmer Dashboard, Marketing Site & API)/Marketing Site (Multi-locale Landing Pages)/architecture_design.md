Built on Next.js App Router with a top-level `app/(site)/[locale]/` route group that parameterizes every page by locale and uses `generateStaticParams` over `LOCALES` plus `force-dynamic` rendering so founder edits in the translations table are visible immediately. The root `[locale]/layout.tsx` injects Google fonts (Playfair, DM Sans, Geist Mono; Arabic Nastaliq/Arabic UI only for non-English locales), sets `lang`/`dir` from `LOCALE_REGISTRY`, and renders a `SuggestionChip` only for English. Each content route (`features`, `how-it-works`, `vision`, `why-agropioo`) is a page that composes reusable `sections/*.tsx` components under its own `sections/` folder, while shared layout chrome (`SiteHeader`, `Footer`, `CTA`) lives in `[locale]/sections/`. Auth-protected entry points (`login`, `signup`) use their own `layout.tsx` files to run server-side guards like `requireGuestPage()` before rendering forms. All copy is fetched via `getCurrentDictionary()` and localized through `localized(t(key), locale)` / `formatNumber(..., locale)`, keeping pages as thin async data fetchers that compose presentational sections.
